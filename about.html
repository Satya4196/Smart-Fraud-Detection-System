About this project

A machine learning web application designed to identify suspicious financial transactions through analytics and predictive modeling.

Project overview

This application combines a Flask backend, a Scikit-learn fraud model, and Bootstrap-driven UI components to create a complete end-to-end portfolio project.

Instead of stopping at model training, the project now includes a public-facing interface, analytical dashboard, evaluation screen, and user interaction pages.

Technology stack
  • Frontend: HTML, CSS, Bootstrap 5
  • Backend: Python, Flask
  • Machine Learning: Scikit-learn Random Forest
  • Visualization: Matplotlib and Seaborn
Dataset information

The dashboard currently works from a sample of {{ "{:,}".format(stats.sample_size) }} transactions to keep the website responsive while still showing realistic fraud behavior and feature relationships.

Core model inputs include transaction step, type, amount, and origin and destination balance values.

Use cases

This design pattern can be reused for banking fraud monitoring, credit risk tools, disease prediction apps, price estimation systems, and recommendation engines.

It is a solid foundation for transforming ML models into professional full-stack products.
